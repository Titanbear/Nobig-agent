# 连接自己的 PC

本客户端是 Flutter 原生 Android App，不是网页或 WebView。当前通信适配目标是具有 Typert HTTP RPC 和 `remote.mux` 的 DSH rc.2 协议。DSH 是运行在 PC 的外部服务，不随 APK 提供；客户端不包含 PC Agent 引擎。

## PC 侧准备

1. 安装并启动支持上述协议的 DSH，在 PC 完成模型、目录和权限设置。
2. 获取其 HTTP 服务地址和本次启动的连接 Token。
3. 同一局域网可以配置可达的局域网地址；外出连接需要自行配置支持 HTTP 和 WebSocket 的 HTTPS 公网入口，或者使用能让两端互通的 VPN。客户端本身不提供 NAT 打洞、端口映射或云端中继。
4. 入口必须保留 DSH Cookie 认证，并正确转发 WebSocket upgrade。如果入口另外要求网页登录或只允许特定 Host/Origin，需要在代理/DSH 侧完成相应配置；App 不绕过这些访问限制。

## 手机侧

打开「电脑」，填写电脑名称、服务地址、连接 Token，点击「保存并连接」。可直接粘贴含 `?token=` 的启动链接：App 会剥离链接中的 Token，再用系统安全存储保存。公网连接要求 HTTPS；本机、局域网与 Tailscale 地址支持 HTTP。

App 使用 Token 换认证 Cookie，再调用 `session/list` 验证接口。仅打开网页成功不会被当成已连接。连接 Cookie 只保存在内存，下一次连接重新认证。

进入「会话」打开已有会话，或者新建对话。新建对话的工作目录是 PC 上的路径，留空由服务端决定。两端通过相同会话 ID 操作 PC 上的同一份会话。

## 当前能力

- 列出普通会话、创建会话、订阅历史与文本输出、发送文本、停止当前会话任务。
- 读取连接断开后重新订阅的会话快照。发送/创建/停止等写操作不自动重试，避免网络切换导致重复执行。
- 手机离开页面或切到后台会释放实时订阅，不主动停止 PC 任务；回到前台后重新订阅。
- 本地演示始终显示演示标识，其内容不来自 PC，也不调用模型。

## 当前限制

- 尚未实现提问/权限审批卡片、图片/文件附件、历史分页、完整工具结果与后台通知。任务需要审批时请先在 PC 完成。
- 不承诺适配 DSH 全部历史版本、所有插件事件或第三方鉴权入口。
- PC 需要保持联网运行。PC 重启导致 Token 失效时，需要更新手机配置。
- 自动化 HTTP/WebSocket 夹具验证不等于真实公网互通；需要用实际 PC 服务地址和 Android 真机联调。
