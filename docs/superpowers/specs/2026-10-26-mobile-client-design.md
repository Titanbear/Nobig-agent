# Nobig Agent 手机客户端骨架

## 已确定的目标

交付可安装的 Android Flutter 客户端，PC 承载单 Agent，手机通过用户配置的服务地址远程交互。手机使用 Wi-Fi 或移动网络；公网可达入口由已有隧道、VPN 或代理配置提供。移动端使用 Flutter 原生组件，不采用 WebView。

本次先完成客户端骨架和最小 DSH rc.2 连接适配，不复制拾忆源码，不新增云端中继，不实现新的 PC Agent 引擎。UI、状态和协议层分离，之后可以替换 PC 引擎、升级界面。

## 页面和数据

- 会话页：连接状态、会话列表、下拉刷新、创建会话、打开聊天。
- 电脑页：电脑名称、服务 URL、DSH 连接 Token、保存并连接、断开、清除配置。
- 聊天页：历史消息、实时文本、运行状态、发送消息、停止任务、连接中断提示。
- 设置页：浅色/深色/跟随系统、明确标注的本地演示模式、版本和能力说明。
- 演示模式仅模拟会话和回复，不联系 PC，不执行工具；页面持续显示演示标识。

PC 是会话和任务的事实来源。手机只保存连接元数据、主题和连接凭据。Token 使用系统安全存储，认证 Cookie 仅保存在当前连接内存；连接元数据和主题使用普通偏好存储。模型 API Key 在 PC 配置。

## 通信边界

`AgentGateway` 封装 connect、listSessions、createSession、watchSession、sendMessage、cancel 和 close。实现包括 DemoGateway 和 DshGateway。后续 PC 引擎仅需新增 Gateway，无需重写页面。

DSH 适配使用启动 Token 换 Cookie、HTTP Typert RPC 和 `/api/remote.mux` 的 `session/follow` 流。会话列表为真实服务探测，HTTP 成功但协议不匹配不能显示已连接。错误提示不展示凭据。URL 中的 Token 被剥离并单独存入安全存储。

网络恢复只重新订阅会话，不自动重发写操作。切换连接、离开聊天页和销毁控制器时释放订阅；旧连接迟到的事件不得覆盖新状态。停止操作只针对当前会话。手机断开不等于取消 PC 任务。前台恢复时刷新/重新订阅，不承诺 Android 后台维持长连接。

## 首版验收

1. 应用能够启动，主要页面可切换，小屏和键盘弹出时没有布局溢出。
2. 未连接时引导配置 PC；错误地址、错误凭据或协议不匹配时显示具体可操作提示。
3. 演示模式可创建会话、发送模拟消息、看到逐步回复并停止，且显示演示标识。
4. DSH 适配通过本地 HTTP/WebSocket 协议夹具验证认证、列表、消息、取消和流事件；未经真实 PC 联调不得声称公网互通完成。
5. `flutter analyze`、`flutter test` 和 Android debug APK 构建通过，或者明确记录环境阻塞和未经验证的项目。

## 后续

真机与 PC DSH 联调、提问/权限卡片、附件上传、完整工具日志、通知、历史分页及公网配对体验逐步加入。当前手机端不执行本地命令。
